# MDDRC5 RC Mixed Mode — CircuitPython

Copy `code.py` to the root of the board's `CIRCUITPY` drive.

The example uses only built-in CircuitPython modules:

- `board`
- `digitalio`
- `pulseio`
- `pwmio`
- `time`

No files need to be copied into the `lib` directory.

Change `RC1_IS_THROTTLE` and the four `MAX_*` values near the top of
`code.py` to suit the RC transmitter and motor alignment.
